# قرارات ما قبل البدء (افتراضية)

لم يحدد الطلب `/calculator` تفاصيل إضافية، فاعتمدتُ القرارات التالية. غيّرها متى شئت.

| البند | القرار |
|---|---|
| نوع الحاسبة | أساسية: + − × ÷ ، نسبة مئوية %، فاصلة عشرية، حذف، مسح |
| الدقة | `BigDecimal` (0.1 + 0.2 = 0.3 بالضبط) والعرض حتى 10 خانات كسرية |
| المعمارية | MVVM + UDF: `StateFlow<UiState>` + أحداث `CalculatorAction` + Reducer نقي |
| الواجهة | Jetpack Compose + Material 3 (ألوان ديناميكية على Android 12+) |
| الحقن | Hilt |
| الحد الأدنى للنظام | minSdk 26 |
| اللغات | الإنجليزية والعربية للنصوص؛ لوحة الأرقام تبقى بنفس الترتيب في RTL |
| الأرقام | ASCII (0-9) فقط، والفاصلة العشرية `.` |
| حفظ الحالة | لا يُحفظ التعبير عند قتل العملية (ViewModel فقط) |
| السجل / الحاسبة العلمية / الأفقي | خارج النطاق حاليًا |

## قواعد الإدخال
- رقم بعد نتيجة نهائية أو خطأ يبدأ تعبيرًا جديدًا؛ المشغّل بعد النتيجة يكمل منها.
- لا أصفار بادئة، وحد أقصى 15 خانة لكل رقم.
- فاصلة ثانية في الرقم نفسه تُتجاهل؛ الفاصلة على رقم فارغ تعطي `0.`
- المشغّل الجديد يستبدل السابق. البداية بـ `-` فقط مسموحة.
- بعد `%` يُتجاهل الرقم والفاصلة.
- `=` تحذف المشغّلات و`.` المعلّقة من النهاية قبل الحساب.
- القسمة على صفر وأي تعبير غير صالح يظهران كرسالة خطأ؛ الحذف أو المسح يزيلانها.
